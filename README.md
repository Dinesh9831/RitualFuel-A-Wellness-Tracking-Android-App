## About

RitualFuel helps users maintain daily wellness routines with structured tracking for:

- **Yoga and Fitness**: Track yoga sessions, workouts, and health routines.
- **Mental Health**: Monitor mental wellness and access guided self-improvement routines.
- **Motivation & Learning**: Daily motivational content, current affairs, and knowledge-based exercises.
- **Interactive Experience**: Smooth navigation with image sliders, interactive layouts, and visual cues.

---

## Features

- ✅ Track daily wellness activities  
- ✅ Guided yoga sessions  
- ✅ Motivational content & self-development modules  
- ✅ Current affairs & knowledge updates  
- ✅ Interactive UI with modern Android design  
- ✅ Multi-activity support: Health, Politics, Geography, History, Mental Health  
- ✅ Offline access to stored resources

## Tech Stack

- **Programming Language**: Kotlin  
- **IDE**: Android Studio  
- **Architecture**: MVVM / Modular  
- **Minimum SDK**: Android API Level 21+  
- **Libraries**:  
  - Glide / Picasso – Image Loading  
  - AndroidX Components – UI & Lifecycle  
  - Retrofit – Network Requests
